REELVAULT - PRIVATE IPHONE MOVIE APP

What works:
- Your 11 existing ratings are preloaded, including their five original answers.
- Watchlist is preloaded with The Killing Room, Ready or Not, Rebirth, You Should Have Left, 13 Sins, Mayhem.
- Search movies using the public Apple iTunes movie catalog (requires internet; results vary).
- Add any missing movie manually.
- Move watched movies from watchlist to a five-question rating form.
- Edit past ratings, delete movies, move back to watchlist.
- Share text lists using iPhone's share sheet (Messages / AirDrop / etc.).
- Export/import backup JSON. Saves locally in your browser's storage.
- No account, no App Store, no analytics, no cloud database.

IMPORTANT: These files are a working app package, not an already-installed iPhone app.
To install as an app, publish these files as a static HTTPS site. Example: create a new GitHub repository, upload the files, then turn on GitHub Pages (Settings > Pages, deploy from main / root). Open the resulting URL in Safari on your iPhone, choose Share > Add to Home Screen, keep 'Open as Web App' enabled, then Add.

Your site address may be publicly accessible even though your personal movie data remains local on the device. If you want the app URL private, use an access-controlled host instead. Export a backup regularly. Browser/device storage may be cleared and does not sync with another device.

Movie lookup and associated artwork come from the Apple movie catalog. Results may not cover every title. Users can manually add missing films. Shared lists are readable snapshots, not live multi-user accounts.

The Platform (2019) is deliberately excluded. No Escape (2020) is marked rated, not on watchlist.
